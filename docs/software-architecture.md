# 双MCU软件架构

## 系统边界

```text
┌──────────────── STM32F407VET6 ────────────────┐
│ 16×TSOP34838 → 中断/输入捕获 → 强度快照       │
│                         → 协议编码 → UART TX   │
└──────────────────────────────┬─────────────────┘
                               │ common红外帧
┌──────────────── STM32L431RCT6▼─────────────────┐
│ UART RX → CRC/序号/16路强度                    │
│ JY61 UART → 航向与偏航角速度                   │
│             ↓                                  │
│      方位估计 → 导航状态机 → 差速混控          │
│             ↓                                  │
│        左PWM              右PWM                │
└────────────────────────────────────────────────┘
```

## 依赖方向

```text
F407 ──┐
       ├──> common（红外链路）
L431 ──┘
```

`common` 不反向依赖任何目标芯片。F407与L431互不链接对方源文件，只通过字节协议协作。

全仓库固件统一使用 C11。硬件抽象采用带 `void *context` 的函数指针结构体，不使用C++类、虚函数、STL、异常或动态分配。

## F407实时路径

1. 16路输入中断或定时器捕获更新有界计数器；
2. 固定周期短临界区内复制并清零计数；
3. 编码固定37字节帧并提交UART DMA；
4. 只有整帧提交成功后递增序号。

## L431控制路径

1. 读取F407和JY61两个UART环形缓冲；
2. 完整校验红外CRC及JY61校验和；
3. 优先处理急停、撤销使能和故障；
4. 对16路强度作圆向量加权，得到相对方位和置信度；
5. 运行搜索、跟踪、穿门、完成或故障状态；
6. 使用红外角度比例项与JY61偏航角速度阻尼形成差速输出；
7. 经硬件层限幅、死区、左右补偿和PWM换算后驱动电调。

## 安全不变量

- 上电和构造阶段双电调必须处于中位；
- 未使能、急停、任务完成、300秒超时和输出故障均输出中位；
- 过期或损坏的传感器帧不能被当作新数据；
- 热路径不使用动态分配、异常、文件系统或网络；
- 主机测试不替代台架、电源完整性和水池测试。
