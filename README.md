# Sailing2026：双MCU红外自主航行

本仓库面向第十五届全国海洋航行器设计与制作大赛 C1 智能航行项目。软件采用两块 MCU：`STM32F407VET6` 负责16路红外探头采集，`STM32L431RCT6` 负责姿态读取、导航决策和双推进器差速控制，不使用上位机。

```text
16×TSOP34838
      │ GPIO/定时器
STM32F407VET6
      │ UART：16路强度帧
STM32L431RCT6 ←UART→ JY61
      │ PWM×2
左右电调 → 双推进器
```

## 当前完成度

已完成可在普通电脑编译验证、无芯片厂商依赖的 C11 核心。固件代码只允许使用 `.c/.h`，不接受 C++ 源码：

- 16路红外强度快照与串口帧发布；
- 带 CRC16 的 F407→L431 固定长度链路；
- JY61 `0x52/0x53` 数据包解析；
- 16探头圆向量方位估计；
- 搜索、跟踪、穿门、十门完成和300秒超时状态机；
- 红外比例转向与JY61偏航角速度阻尼；
- 撤销使能、急停和执行器故障归零。

尚未包含 STM32Cube 生成代码、芯片启动文件和具体引脚初始化。当前接口已经隔离好，硬件资料齐全后分别实现F407和L431的HAL即可。

## 仍需提供的硬件信息

- 两块控制板的原理图或 STM32CubeMX `.ioc` 工程；
- F407上16个TSOP34838对应的GPIO/定时器通道；
- F407与L431之间的UART实例、引脚、波特率和接线；
- L431与JY61的UART引脚、波特率、具体版本和安装轴向；
- L431左右电调PWM引脚；
- 电调型号、PWM范围、频率、解锁流程和正反转能力；
- 启动开关、急停、LED和蜂鸣器引脚；
- F407探头板已有程序或真实串口抓包（若存在）；
- CGQ1是否指向船头、CGQ2相对CGQ1的旋转方向及最终装配方向。

## 验证

```powershell
.\scripts\validate.ps1 -Cc 'D:\MinGW\mingw64\bin\gcc.exe'
```

该命令使用 `gcc -std=c11` 分别构建并运行F407与L431测试。主机测试通过只证明协议和状态机行为正确，不等同于完成实船验证。
