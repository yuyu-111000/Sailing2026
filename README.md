# Sailing2026

本仓库面向第十五届全国海洋航行器设计与制作大赛 C1 智能航行项目。软件采用两块 MCU：`STM32F407VET6` 负责16路红外探头采集，`STM32L431RCT6` 负责姿态读取、导航决策和双推进器差速控制。

```text
16×TSOP34838
      │ GPIO/定时器
STM32F407VET6
      │ UART：16路强度帧
STM32L431RCT6 ←UART→ JY61
      │ PWM×2
左右电调 → 双推进器
```
