# Sailing2026：双MCU红外自主航行

本仓库面向第十五届全国海洋航行器设计与制作大赛 C1 智能航行项目。软件采用两块 MCU：`STM32F407VET6` 负责16路红外探头采集，`STM32L431RCT6` 负责姿态读取、导航决策和双推进器差速控制，不使用上位机。

```text
16×TSOP34838
      │ GPIO/定时器
STM32F407VET6
      │ UART：16路强度帧
STM32L431RCT6 ←UART→ JY61
      │ PWM×2
左右电调 → 双推进器
```

## 当前完成度

已完成可在普通电脑编译验证的、无厂商依赖的 C++17 核心：

- 16路红外强度快照与串口帧发布；
- 带 CRC16 的 F407→L431 固定长度链路；
- JY61 `0x52/0x53` 数据包解析；
- 16探头圆向量方位估计；
- 搜索、跟踪、穿门、十门完成和300秒超时状态机；
- 红外比例转向与JY61偏航角速度阻尼；
- 撤销使能、急停和执行器故障归零。

尚未包含 STM32Cube 生成代码、芯片启动文件和具体引脚初始化，因为两块板的原理图、`.ioc`、电调型号及引脚表尚未提供。当前接口已经隔离好，资料齐全后只需分别实现两个目录中的 HAL。

## 验证

```powershell
.\scripts\validate.ps1 -Cxx 'D:\MinGW\mingw64\bin\g++.exe'
```

该命令分别构建并运行 F407 与 L431 测试。主机测试通过只证明协议和状态机行为正确，不等同于已经完成实船验证。

## 供电约束

比赛全部能量必须来自主办方提供的4节5号干电池。超级电容是否允许以及检录时能否带电，需要取得组委会书面确认；当前软件不依赖超级电容。
